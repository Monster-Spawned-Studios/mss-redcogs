# Contributing To This Project

We welcome contributions to this project. Please read the following guidelines before submitting your pull request.

## Pull Request Process

1. Fork the repository.
2. Create a new branch with a descriptive name.
3. Make your changes.
4. Test your changes.
5. Commit your changes.
6. Push your branch to your forked repository.
7. Submit a pull request.

## General Guidelines

- Check the project's [README](../README.md) file for any requirements or guidelines.
- Please ensure that you have followed the coding standards and formatting conventions set in the [README](../README.md).
- Please write clear, concise, and descriptive commit messages.
- Keep your code clean and organized.
- Make sure to test your changes thoroughly before submitting.
- If your changes are not backward-compatible, please mention this in the pull request description.
- Avoid writing comfusing, long, or undocumented code, as it will make it harder for others to understand and maintain it and will most likely cause merge conflicts (and likely result in a rejection of your contribution).
- If you have any questions, feel free to ask in the pull request.
- Please be patient, as it may take some time to review your pull request, issues, etc.

## Code of Conduct

By contributing to any and all projects in the Monster Spawned Studios community, you agree to abide by the Monster Spawned Studios' [Code of Conduct](./CODE_OF_CONDUCT.md). This document is subject to change at any time, and it is your responsibility to keep up-to-date with the latest version. To view the code of conduct, please refer to the [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) file.
